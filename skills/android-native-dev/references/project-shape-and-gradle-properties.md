# Android project shape and gradle.properties

The minimum files a new Android module needs, and the `gradle.properties`
baseline. Add only what the project is missing.

## Minimum project shape

`gradle.properties`, `settings.gradle.kts`, `build.gradle.kts`,
`gradle/wrapper/`, `app/build.gradle.kts`,
`app/src/main/AndroidManifest.xml`, `app/src/main/java/.../MainActivity.kt`,
`app/src/main/res/values/{strings,colors,themes}.xml`.

## gradle.properties

```properties
android.useAndroidX=true
org.gradle.parallel=true
kotlin.code.style=official
# org.gradle.jvmargs=-Xmx4096m   # raise only on a real OutOfMemoryError
# android.enableJetifier=true    # legacy support-library deps ONLY; deprecated
#                                 in AGP 9, removal announced for AGP 10
```

## Two AGP 8+ traps that look like missing code

- `BuildConfig` is **not generated by default** → add
  `android { buildFeatures { buildConfig = true } }` before using it.
- Variant task names are `{flavor}{BuildType}` (`devDebug`, `prodRelease`);
  `installDevDebug` installs, `connectedDevDebugAndroidTest` needs a device.
